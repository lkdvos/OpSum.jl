Building operators

A short guide to the operator interface. The example pages (starting with Spin chains) work through concrete models; Reference lists every docstring.

TensorMap ──project(O, B)──► SiteOperator / LocalOperator ──A[i], B[i, j]──► Terms ──opsum(lat, …)──► OperatorSum ──mpo──► SymbolicMPO
spin_ops, fermion_ops, … ───┘

A site is an operator Basis: an ordered list of operators on the physical space, identity first. A bag of Terms carries no lattice; the lattice (one basis per site) enters when terms are added to an OperatorSum, the one container that mpo, instantiate and islossless take. Everything is exported except dot (using LinearAlgebra: dot).

Never write alphabet letters by index

Behind every operator are letters IrrepOperator(c, n), the n-th basis element of charge c. Their order depends on how the basis was built, so hard-coding an n silently changes the Hamiltonian when the basis changes. Use builder entries or project and let OpSum find the letters.

On-site operators

Each common site has a basis (spin_basis, fermion_basis, boson_basis, hubbard_basis, tj_basis; the symmetry is an argument) and a builder of the same stem (spin_ops, fermion_ops, boson_ops, hubbard_ops, tj_ops). A builder returns a NamedTuple of every charge-neutral operator the symmetry admits, expanded in the basis and named after TensorKitTensors.jl. Single-site entries are SiteOperators, multi-site entries unplaced LocalOperators. The stock bases are complete, so products and H' never leave them.

using OpSum, TensorKit

B = spin_basis(U1Irrep)
ops = spin_ops(U1Irrep)
keys(ops)
(:S_z, :S_z_S_z, :S_plus_S_min, :S_min_S_plus, :S_exchange)

Any other operator is a TensorMap handed to project; the expansion is exact and checked, and it throws if the operator is outside the span of the basis.

Bc = spin_basis()                  # no symmetry
Vc = space(Bc)
σx = project(TensorMap(ComplexF64[0 1; 1 0], Vc ← Vc), Bc)
SiteOperator{TensorKitSectors.Trivial}(ITO(Trivial(), n=2) + ITO(Trivial(), n=3))

Basis(ops; complete = true) builds a basis of your own from neutral operators. Operators that appear in your Hamiltonian should be elements of the basis: the same model in a poorer basis (e.g. matrix units) has more letters per term and a larger bond dimension. scalarop(c, I) is a multiple of the identity, which is a pass-through and dropped on placement.

Placing and multiplying

A[i] places a SiteOperator; B[i, j] places a LocalOperator on explicit increasing sites, B[i] on i:i+K-1. Sites need not be adjacent. * between placed operators is the operator product in the order written.

term = ops.S_plus_S_min[2, 5]
szz = ops.S_z[1] * ops.S_z[2]
szz ≈ ops.S_z_S_z[1, 2]
true
  • Site order is free: out-of-order terms are braided into site order (for fermions, the anticommutation sign; f_plus_f_min[i + 1, i] is written as it reads).
  • A product on a repeated site is resolved in the site's basis when it enters an OperatorSum (until then length and ≈ on the bag throw).
  • * needs the factors' total charges to fuse to one sector, which neutral operators always do.
ex = spin_ops(SU2Irrep).S_exchange
three = ex[1, 2] * ex[2, 3]          # shared site multiplied in the basis
four = ex[1, 3] * ex[2, 4]           # interleaved sites
(typeof(three), typeof(four))
(OpSum.Terms{TensorKitSectors.SU2Irrep}, OpSum.Terms{TensorKitSectors.SU2Irrep})

LocalOperators add, subtract and scale, and B + α adds a pass-through slot. Placed and unplaced operands cannot be mixed in one call.

Projecting a block

A K-site TensorMap (neutral, or with a trailing Vect[I](tot => 1) leg) is projected into a basis, or a list of bases, one per slot, giving a LocalOperator to place with [i].

Bu = spin_basis(U1Irrep)
hbond = instantiate(
    opsum(
        FiniteChain(Bu, 2),
        (1 / 2) * ops.S_plus_S_min[1, 2] + (1 / 2) * ops.S_min_S_plus[1, 2] + ops.S_z_S_z[1, 2],
    )
)
Bxxz = project(hbond, Bu)
OpSum.LocalOperator{TensorKitSectors.U1Irrep}(Terms(1.0 + 0.0im * [sites=[1, 2], ops=OpSum.IrrepTensorOperators.IrrepOperator{TensorKitSectors.U1Irrep}[ITO(Irrep[U₁](0), n=2), ITO(Irrep[U₁](0), n=2)], total=Irrep[U₁](0)] + 0.5 + 0.0im * [sites=[1, 2], ops=OpSum.IrrepTensorOperators.IrrepOperator{TensorKitSectors.U1Irrep}[ITO(Irrep[U₁](1), n=1), ITO(Irrep[U₁](-1), n=1)], total=Irrep[U₁](0)] + 0.5 + 0.0im * [sites=[1, 2], ops=OpSum.IrrepTensorOperators.IrrepOperator{TensorKitSectors.U1Irrep}[ITO(Irrep[U₁](-1), n=1), ITO(Irrep[U₁](1), n=1)], total=Irrep[U₁](0)]), 2)

Charged operators: couple and dot

couple fuses placed charged operators to a total charge (default the unit sector), and dot is the Cartesian Sᵢ·Sⱼ. For three or more operands under a non-abelian symmetry, nest couple(couple(a, b; to = j), c) or list the options with couple_channels.

Bs = spin_basis(SU2Irrep)
Sv = project(Bs[2], Bs)                     # the spin vector: the charge-1 element
chirality = couple(Sv[1], Sv[2], Sv[3])
Terms(1.0 + 0.0im * [sites=[1, 2, 3], ops=OpSum.IrrepTensorOperators.IrrepOperator{TensorKitSectors.SU2Irrep}[ITO(Irrep[SU₂](1), n=1), ITO(Irrep[SU₂](1), n=1), ITO(Irrep[SU₂](1), n=1)], total=Irrep[SU₂](0)])

OperatorSum and the hermitian conjugate

opsum(lat, terms...) makes one pass over each argument (iterables nest) and checks every letter and site as it is added. opsum!(H, terms...) / append! mutate; + copies, so do not fold it over thousands of terms. A lattice is FiniteChain(B, N), FiniteChain([B₁, B₂, …]), InfiniteChain(B) or InfiniteChain([B₁, B₂]). H' builds the hermitian conjugate, so a hopping only has to be written once; it needs a lattice, so a bare Terms has none.

Bf = fermion_basis(U1Irrep)
F = fermion_ops(U1Irrep)
flat = FiniteChain(Bf, 2)
T = opsum(flat, -1.0 * F.f_plus_f_min[1, 2])
T + T' ≈ opsum(flat, -1.0 * (F.f_plus_f_min[1, 2] + F.f_plus_f_min[2, 1]))
true
Hxxz = opsum(FiniteChain(Bu, 6), Bxxz[i] for i in 1:5)
length(Hxxz)
15

Building the MPO

W = mpo(Hxxz)
map(length, W.bondsectors)       # reduced bond dimension per bond
6-element Vector{Int64}:
 4
 5
 5
 5
 4
 1

W.Ws[i] is the sparse bond matrix at site i and W.bondsectors[i] the charge of each bond index to its right. irrep_mpo_tensors(W) assembles symmetric TensorMaps. The optional second argument picks the bond algorithm: BipartiteAlgorithm() (default, lossless minimum vertex cover) or SVDBondAlgorithm(trunc; sweep) with a MatrixAlgebraKit truncation strategy. sweep = IndependentSVD (default) keeps k indices per bond; SequentialSVD keeps k after upstream truncation.

mpo(H, SVDBondAlgorithm(truncrank(8)))
mpo(H, SVDBondAlgorithm(truncrank(8); sweep = SequentialSVD))

jordan_mpo_tensors emits one BlockTensorKit.SparseBlockTensorMap per site in Jordan form, and with MPSKit loaded instantiate(mpo(H)) builds its FiniteMPOHamiltonian / InfiniteMPOHamiltonian (see the MPSKit example page). Jordan emission requires total charge unit(I); operators you measure (magnetisation, correlators) compress by the same mpo call, but a charged one is refused by jordan_mpo_tensors.

Wsj = jordan_mpo_tensors(Hxxz)
map(W -> size(W, 4), Wsj)
6-element Vector{Int64}:
 5
 5
 5
 5
 5
 1

Checks, cheapest first: islossless(H) (symbolic, any N, assumes lossless compression); mpo_tensormap(irrep_mpo_tensors(W)) ≈ instantiate(H) (dense oracle); and a spectrum comparison of instantiate(H) (examples/common.jl has helpers).

islossless(Hxxz), mpo_tensormap(irrep_mpo_tensors(W)) ≈ instantiate(Hxxz)
(true, true)

Infinite chains

On an InfiniteChain the same terms give an infinite MPO with a unit cell of length(chain) sites. The terms are a generating set, one representative per translation class: the operator is $\sum_n \mathrm{translate}(H, nL)$. Terms must be neutral and non-empty (K ≥ 1), and SVDBondAlgorithm is not available.

chain = InfiniteChain(Bu)
Hgen = opsum(
    chain, 0.5 * ops.S_plus_S_min[1, 2] + 0.5 * ops.S_min_S_plus[1, 2] + ops.S_z[1] * ops.S_z[2]
)
Hinf = mpo(Hgen)
Hinf.bondsectors, Hinf.start, Hinf.finish
(Vector{TensorKitSectors.U1Irrep}[[0, 0, 1, -1, 0]], [1], [5])

Exponentially decaying interactions

expterm adds $\sum_{i<j} \lambda^{j-i-1} A_i S_{i+1}\cdots S_{j-1} B_j$ with $0 < |\lambda| < 1$, from one representative term; it goes into the same OperatorSum on either lattice.

Hexp = opsum(
    chain,
    0.5 * ops.S_plus_S_min[1, 2] + 0.5 * ops.S_min_S_plus[1, 2],
    expterm(ops.S_z_S_z[1, 2]; decay = 0.6),
)
mpo(Hexp).bondsectors
1-element Vector{Vector{TensorKitSectors.U1Irrep}}:
 [0, 1, -1, 0, 0]
  • decay counts per site of the string; |λ| ≥ 1 is rejected.
  • exitsite (default: the representative's last site) is the first site of the exit block.
  • string is a neutral on-site operator carried by the gap (default: identity); the sites a channel touches must share one basis.
  • A sum of exponentials is a sum of expterms, one bond index per distinct λ.
  • On a finite chain the sum is truncated to the chain (OpSum.chain_terms(H) spells it out). Use the smallest unit cell you can, since a channel's period is part of its declaration.
